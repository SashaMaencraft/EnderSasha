# 🚀 EnderSasha · Биография + Донаты + ifo + MAX

Современная адаптивная веб-страница-визитка, объединяющая личную биографию, систему донатов, информационный портал и официальное заявление о присутствии в мессенджере MAX.

## 📖 О проекте

Этот проект представляет собой **одностраничное приложение (SPA)** с четырьмя основными вкладками:

- **Биография** — информация о персонаже, хронология, факты, социальные ссылки и блок с маркетплейсами (Wildberries, Ozon, Яндекс Маркет).
- **Донаты** — платформы для поддержки автора (Boosty, Donation Alerts, Cloudtips, Т-Банк) с юридической информацией.
- **ifo** — информационный портал с поиском по проектам и переключателем темы.
- **MAX** — официальное заявление об отсутствии аккаунтов в мессенджере MAX, список фейковых каналов и контакты.

## ✨ Ключевые особенности

| Особенность | Описание |
|-------------|----------|
| **Адаптивный дизайн** | Корректно отображается на любых устройствах (mobile-first) |
| **Тёмная/светлая тема** | Переключение с сохранением выбора в `localStorage` |
| **Анимированный фон** | Частицы с эффектом соединения линиями |
| **Нижняя навигация** | Удобный доступ к вкладкам на мобильных устройствах |
| **Всплывающие подсказки** | Для маркетплейсов и верификационных значков |
| **Пасхалка** | 5 кликов по аватару открывают секретный код |
| **Модальные окна** | Политика данных, пользовательское соглашение, контакты |
| **Поиск по проектам** | Быстрый поиск в разделе ifo |
| **Telegram WebView** | Специальная оптимизация для встроенного браузера Telegram |

## 🛠️ Технологии

- **HTML5** — семантическая разметка
- **CSS3** — кастомные свойства, `clamp()`, `backdrop-filter`, анимации, медиа-запросы
- **JavaScript (Vanilla)** — вкладки, модалки, поиск, переключение темы, частицы
- **Font Awesome 6** — иконки
- **Google Fonts (Inter)** — основная типографика
